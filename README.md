# INVITRO Marketplace

Отдельный продуктовый проект по маркетплейсу лабораторных услуг INVITRO для государственных и корпоративных заказчиков.

> Не смешивать с ПРИИЗ и интерактивной картой INVITRO.

## Статус

- evidence-backed AS-IS собран;
- границы MVP №1 определены;
- информационная архитектура собрана;
- кликабельный прототип v0.2 приведён к фирменной визуальной системе INVITRO;
- основной цвет интерфейса: `#E6007E`;
- визуальная система: белый + графит + INVITRO magenta + нейтральный серый;
- фиолетовые акценты исключены.

## MVP №1

В первой версии продаются только собственные услуги INVITRO.

Клиентский flow:

`Главная → Каталог → корзина → ИНН → реквизиты → документы → верификация ДКП → КП → договор/счёт → сотрудники → исполнение → статус → закрывающие документы`

Backoffice ДКП:

`Очередь → карточка заказа → верификация → КП и версии → документы → оплата → handoff в исполнение → исключения → audit trail`

## Продуктовый принцип

Marketplace не должен становиться новым ЛИС, бухгалтерской системой, ЭДО или системой медицинских результатов. Где возможно, используются существующие контуры INVITRO через интеграции/deep-links.

## Этап №2

Внешний marketplace нескольких лабораторий и сравнение предложений - отдельный следующий этап после проверки внутреннего marketplace INVITRO.
